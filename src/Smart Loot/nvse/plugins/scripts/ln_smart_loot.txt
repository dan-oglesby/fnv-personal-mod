; Smart Loot (Dan, 2026-11-14): auto-loot that takes what is useful to you now instead of whole
; categories. Ammo for the weapons you carry (up to a cap), weapons with more DPS than your best,
; spares for repairs, weapon mods that fit, a few of each aid item, keys, notes, anything weightless
; with value, and anything else worth enough caps per pound. Loose items, unowned containers (unlocked
; with your skill when that's no crime) and corpses, within reach, never stealing.
;
; Settings: equip the Scavenger's Duffel (Smart Loot) from the Pip-Boy's Apparel tab; the menu opens
; when you close the Pip-Boy. The duffel is given on the first load and again if it is ever lost.
; It lives in SmartLoot.esp (one item and three empty form lists, made by make_plugins.py).
;
; Also auto-consume (Survive.txt): water and food just before Hardcore penalties, RadAway and Rad-X,
; a doctor's bag for crippled limbs, and a stimpak only in dire straits. Settings page 3.
;
; Run by JIP LN NVSE's script runner (ln_: new game and every load). Needs xNVSE 6.4+, JIP LN,
; JohnnyGuitar NVSE (for the Pip-Boy DPS) and ITR NVSE (UseAidItem, for auto-consume). Re-registering on every load is safe: xNVSE clears
; repeating calls on load and new game, and the equip handler is removed before it is added again.

	;   the settings menu (optional: if a page fails, the duffel doesn't open it, looting carries on
