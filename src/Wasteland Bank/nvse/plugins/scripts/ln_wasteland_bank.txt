; Wasteland Bank (Dan, 2026-11-11): a rewrite of "Bank Card" (BankCard.esp, Nexus 39741, 2011)
; without its bugs. Since 2026-11-16 money has weight and cash moves through courier squads you
; call with the card (fees: 2 percent of cash moved, 1 cap a pound for the vault); see
; docs/wasteland-bank-couriers.md. Deposit and withdraw caps with daily interest, take a loan with weekly
; interest, convert NCR, Legion and pre-war money (and caravan money) to caps, and optional
; auto-deposit and auto-convert.
;
; Open the bank like the original: equip the Wasteland Bank Card from the Pip-Boy's Apparel tab,
; and the bank opens when you close the Pip-Boy. The card is given on the first load and again
; if it is ever lost. It lives in WastelandBank.esp (one item, no scripts; made by
; make_plugins.py). From the console: call (CompileScript "WastelandBank/Open.txt")
;
; Run by JIP LN NVSE's script runner (ln_: new game and every load). The menus and bookkeeping are
; user-defined functions in Data\nvse\user_defined_functions\WastelandBank\, compiled by xNVSE
; at startup. Balances are JIP auxiliary variables on the player ("_wb..."), kept in JIP's
; co-save. Needs xNVSE 6.2.8+, JIP LN 56.95+.
;
; Re-registering here on every load is safe: xNVSE clears repeating calls on load and new game,
; and the equip handler is removed before it is added again.

; Every function must have compiled. xNVSE compiles them at startup; a failed one comes back
; empty, and a timer or event handler that calls an empty function can crash xNVSE (2026-11-13:
; two crashes in nvse_1_4.dll that way, from a variable named like a console command). So if any
; failed, register nothing and say so.
