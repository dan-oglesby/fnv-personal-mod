; Target Readout: default settings, set once per save (JIP auxiliary variables on the player, kept
; in JIP's co-save). Change them from the console, e.g. player.AuxVarSetFlt "_trRange" 5000
; Saves made with an older settings version get only the settings added since (add new versions
; above this one's block, in rising order).
begin Function {}
	if eval (player.AuxVarGetFlt "_trInit") >= 1
		return
	endif
	; version 1 (2026-11-17): a new save, or the first load with this mod
	player.AuxVarSetFlt "_trInit" 1
	player.AuxVarSetFlt "_trOn" 1		; the readout is on (0 hides it)
	player.AuxVarSetFlt "_trRange" 3000	; actors up to 3000 units away (about 43 m)
	player.AuxVarSetFlt "_trRed" 1		; text colour: 1 red, 0 the HUD colour, 2 the HUD's alternate colour
end
